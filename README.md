# Instant Small Loan Website

A simple loan website that allows users to view loan information and apply for small loans between **₹1000 – ₹5000**.

## Features

* Simple landing page
* Loan application form
* About page
* Contact page
* Easy navigation

## Loan Details

* Minimum Loan: ₹1000
* Maximum Loan: ₹5000
* Simple online application process

## Project Structure

loan-website
│
├── index.html
├── apply.html
├── about.html
└── contact.html

## How to Use

1. Open the website home page.
2. Click **Apply Loan**.
3. Fill in your details.
4. Submit the loan application.
